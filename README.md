## The Story
I have a child and we plays a lot card games, bricks, toys etc. and finally bored and got the idea

"Charades"

But how many movie names children knows?

So i created a fully-offline playable PWA games like "Charades" but shows only one word and children try to explain the word with hand gestures within timeout.

It builds self-confidence also improve vocabulary for children and support their improvements.

<p>
  <a href="https://mimik.syseng.app/" target="_blank">Try The MIMIK</a>
</p>

## Project
* Built-in support two languages `tr`, `en`.
* Nearly `300` word in both languages
* Timeout starts automatically `30 seconds` up to `60 seconds`
* Detect browser/device languages automatically
